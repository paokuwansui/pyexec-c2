### C-03 D-06 线程硬终止

你要求客户端可以硬终止任意阻塞任务。

Python 线程无法安全、可靠、无损地强杀：

- `PyThreadState_SetAsyncExc` 是 best-effort，可能留下锁、半写文件、坏状态；
- 进程池能硬杀，但与“共享全局运行时”冲突。

需要确认：

- 接受“协作取消 + best-effort 异步异常”，不保证资源完全干净？
- 还是允许对可取消任务改用子进程隔离实现硬终止？
- 还是只对明确标记为可硬终止的任务启用强制终止？

**建议**：v1 采用协作取消 + best-effort 终止；对标记为 hard-kill 的任务用隔离子进程，普通插件仍在线程池中共享全局。

## D-01 Web 客户端如何满足 TCP 控制连接

### 问题

浏览器原生不支持任意 TCP Socket。Web 客户端如何与服务端建立“TCP 控制连接”？

### 可选方案

A. **WebSocket over TCP（推荐）**
- 浏览器通过 WebSocket 连接服务端；
- WebSocket 底层就是 TCP；
- AI 客户端可使用 HTTP JSON over TCP 或 WebSocket；
- 实现简单，适合 Web。

B. **独立桌面壳 + 原生 TCP**
- Web UI 运行在 Electron/桌面壳中；
- 桌面壳提供原生 TCP 桥；
- 更符合“原生 TCP”字面要求；
- 部署复杂、体积大。

C. **双通道**
- Web 使用 WebSocket over TCP；
- 另开原生 TCP 端口给 AI/桌面客户端；
- 两套连接语义必须统一。

### 推荐

A，除非你明确要求“必须浏览器之外的原生 TCP 客户端”。

### 需要你确认

> D-01 选择：A / B / C

## D-03 植入物加密实现

### 问题

植入物必须做什么程度的加密？是否允许第三方加密库或携带纯 Python 加密实现？

### 可选方案

A. **允许携带第三方加密库**
- 例如 `cryptography`；
- 性能与安全性较好；
- 目标环境可能没有库，载荷变大，兼容性下降。

B. **允许携带纯 Python AEAD 实现（推荐）**
- 例如 ChaCha20-Poly1305 的纯 Python 实现；
- 目标端只需 Python；
- 性能和审计成本更高；
- 需要安全测试向量。

C. **仅使用标准库自定义构造**
- 例如 HKDF-SHA256 + 流式 PRF + HMAC；
- 依赖最低；
- 但属于自定义密码构造，审计风险最高。

D. **仅对有 TLS 的传输使用加密，UDP/DNS/ICMP 只做混淆**
- 实现简单；
- 违反“所有流量必须应用层加密”的思想，不推荐。

### 推荐

B。服务端可用 `cryptography` 加速，植入物带纯 Python AEAD 回退。

## D-04 插件签名机制

### 问题

插件签名使用对称 HMAC 还是非对称签名？

### 可选方案

A. **HMAC-SHA256 预共享密钥**
- 标准库即可；
- 实现简单；
- 服务端和植入物必须共享密钥；
- 难以做第三方发布者信任链。

B. **Ed25519 非对称签名（推荐）**
- 服务端持有私钥，植入物只存公钥；
- 适合插件发布与吊销；
- 需要 `cryptography` 或纯 Python Ed25519 实现。

C. **双模式**
- v1 用 HMAC；
- 后续升级 Ed25519。

### 推荐

B；若加密依赖策略不允许，则 C。

### 需要你确认

> D-04 选择：A / B / C

## D-06 植入物任务执行模型

### 问题

多任务并行、无默认超时，使用线程、进程，还是协程？

### 可选方案

A. **线程池 + 共享运行时全局（推荐）**
- 符合“全局可修改”的思想；
- 插件可以直接改协议/密钥；
- 同步插件代码容易执行；
- 不能安全强制杀死阻塞线程。

B. **进程池**
- 隔离性强；
- 但共享全局变量困难，协议热切换和结果队列需要跨进程通信；
- 不适合当前思想。

C. **asyncio 协程**
- 适合 IO；
- 不适合任意阻塞 Python 插件；
- 无法兼容同步插件。

### 推荐

A。取消以协作取消标记为主，辅以隔离终止扩展点。

## C-17 所有下发 Python 代码剥离注释

### 最终决策

所有服务端发往植入物执行的 Python 代码，一律在服务端出口剥离注释。

覆盖：

- 植入物插件；
- 客户端上传的 `.py`；
- raw `python.exec`；
- 协议升级脚本；
- 单阶段载荷中的执行代码；
- 未来所有下发代码通道。

实现约束：

- 使用 `tokenize`，不能用正则粗暴处理；
- 字符串中的 `#` 不能误删；
- 保留行号与缩进；
- 剥离后必须 `compile` 校验；
- 失败则拒绝下发；
- 服务端保存原始源码；
- 植入物只收到剥离后的代码。
